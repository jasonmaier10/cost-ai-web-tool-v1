## Using Cost AI

### Run from local files

1. Clone or download the repository.
2. Find the project’s main HTML file.
3. Open that file with a modern web browser.
4. Interact with the AI interface included in version 1.

### Start a local HTTP server

When direct file access is not appropriate for the browser or environment, launch a server from the repository folder:

```bash
python -m http.server 8000
```

Open the following address:

```text
http://localhost:8000
```

The available behavior and interactions are determined by the interface included in the version 1 release.
